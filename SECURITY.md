# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put users at risk. Use GitHub's **Report a vulnerability** option under the repository's Security tab when available, or contact the maintainer through the repository owner's profile.

Include the affected file, reproduction steps, expected impact, and any suggested mitigation. This project has no server, authentication, database, package dependencies, or bundled secrets; the main security surfaces are unsafe example code, external resource loading, and generated HTML content.
