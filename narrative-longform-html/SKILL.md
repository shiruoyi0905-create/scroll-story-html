# Narrative Longform HTML — 叙事长图文

## 何时用

把一个**复杂概念/技术原理/产品机制**讲给非专家听，产出一篇可滚动的精美单页 HTML。典型："把 OneRec 生成式推荐讲清楚""科普一下 XX 是怎么工作的""照这个精美页面的风格做一份"。

不是这个技能：要给老板拍板/要资源的分页汇报 → 用 `boss-report-deck`；要移动端可交互原型 → 用 `mobile-prototype`。

## 三大支柱（精美的底层原因）

精美 = 克制的设计系统 + 手写 SVG + 故事线叙事。缺一个就塌。

### 1. 克制的设计系统（最重要）

铁律：**墨色分三级 + 品牌色只点缀**。所有"高级感"都来自层次清楚、不滥用颜色。

- 底色不用纯白，用纸感米色 `#FAF7F2`；正文不用纯黑，用墨色 `#2A2622`
- 墨色分三级：正文 `--ink` / 次要 `--ink-2` / 最弱图注 `--ink-3`
- 品牌色只出现在强调词、图标、关键数字、箭头上，**绝不铺大面积**
- 高级悬浮阴影配方：`box-shadow:0 20px 40px -30px rgba(60,40,20,.2)`（大模糊+大负扩散+低透明度），比默认硬阴影高级得多
- 语义标签映射视觉：`<em>` 重定义成"橙色不斜体"当强调，`<b>` 只加深不变色

### 2. 手写 inline SVG 示意图

每张图都手写 SVG，**不用截图、不用图库**。好处：矢量清晰、风格 100% 统一（复用同一套色变量）、随时改字。

套路：`viewBox="0 0 800 320"` 固定画布 → `<g transform="translate(x,y)">` 分组摆放 → 圆角 `<rect rx>` 当卡片 → `<path>` 一条线+一个尖画箭头 → `<text text-anchor="middle">` 标注。常见图元：漏斗（叠放梯形 path）、时间轴（一条 line + 圆点节点）、流程（卡片+箭头）、循环（4 节点+弧线箭头 marker）、架构（分组嵌套矩形）。

### 3. 故事线叙事

不罗列知识点，用一条故事线贯穿：**主角 + 场景 + 疑问 → 旧世界 → 新世界 → 拆解 → 回到开头**。

- 每个 `.scene` 标题写**一句带钩子的话**，不是干名词。反例"数据过滤"，正例"倒数第 1 版去了哪儿？"
- 先讲人话、多举例（用 `.bubble` 气泡），再点核心洞察（用 `.aha` 顿悟框）
- 长文可用 `.act-divider` 分两幕（如"前台故事 + 幕后实现"）

## 工作流

```
- [ ] 1. 澄清：主题、受众（多外行）、深度、要不要出图/PDF
- [ ] 2. 写故事线脚本：主角是谁、遇到什么、旧法 vs 新法、分几个 scene
- [ ] 3. 复制模板骨架 assets/template.html 起手
- [ ] 4. 逐 scene 填：钩子标题 + 正文 + bubble + 一张手写 SVG + aha
- [ ] 5. 自检 + 可选出图（headless Chrome / PDF）
```

第 2 步是关键——**先把脚本写成"谁遇到什么然后呢"，再动手写 HTML**。跳过脚本直接写，必然写成知识点罗列。

## 起手模板

`assets/template.html` 是空白骨架，含全套设计变量、`.hero/.scene/.bubble/.aha/.figure/.act-divider` 组件和一个 SVG 示意图示例。直接复制改内容：改 `--brand` 换主题色，复制 `.scene` 块做新章节。

## 出图 / PDF（可选）

需要静态图或 PDF 时用 headless Chrome（详见 headless-screenshot-tricks 技能）：

```bash
# 整页长图（新版 Chrome 用 --headless=new）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --screenshot=out.png --force-device-scale-factor=2 \
  --window-size=940,4000 --hide-scrollbars file:///绝对路径.html
```

坑：SVG 里的 CSS 动画在截图模式会定格；相对路径引本地图会显灰，SVG 内联所以不受影响，这也是优先手写 SVG 的原因之一。

## 自检清单

- [ ] 底色是纸感米色、正文是墨色，都不是纯黑白
- [ ] 品牌色只点缀，没有大面积铺色
- [ ] 每个 scene 标题是"带钩子的话"，不是干名词
- [ ] 每个关键概念配了一张手写 SVG，配色只用色变量
- [ ] 有故事线贯穿（主角/场景），不是知识点罗列
- [ ] 全中文标签，术语按中国读者习惯
- [ ] 存到 outputs/ 并给 file:// 链接
